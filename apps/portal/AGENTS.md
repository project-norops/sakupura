【サクプラ (100apps) AI作業プロトコル】

1. [作業前] 
   ・タスク開始前に AGENTS.md と DEVELOPMENT_LOG.md を確認する。

2. [実装・変更] 
   ・指示されたコードの作成・修正を行う。

3. [自動検証 (ビルドチェック)]
   ・実装後、必ず背景ターミナルで `npm run build` (または型チェック) を実行する。
   ・エラーが出た場合は自力で修正・解決し、ビルドが通る状態にする。

4. [ログ自動追記]
   ・`DEVELOPMENT_LOG.md` に日時、作業内容、ビルド結果を自動で記録する。

5. [自動 Git & GitHub Push]
   ・`git add .` -> `git commit -m "feat/fix: 作業内容"` -> `git push` までを一連のフローとして自動実行する。
   ・人間からの追加プロンプトや許可を待たずに、Push完了までを1回のターンで終わらせること。
